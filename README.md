# S. Sons Sabharwal's Bakehouse

Single-page website for S. Sons Sabharwal's Bakehouse, Faridabad (since 1985): fresh cakes, cookies and corporate gift hampers.

- `index.html`: the whole site (HTML, CSS and JS in one file)
- `img/`: product, gallery and store photos, plus the logo

Features: three hamper tiers, a corporate gifting section, and an enquiry builder that sends the order brief straight to WhatsApp (+91 98103 23850). It also includes Bakery schema markup for Google and AI search.

To deploy, upload `index.html` and `img/` to any static host (Vercel, Netlify, GitHub Pages or cPanel). There's no build step.
